
# Offline AI Document Assistant

An offline-first personal AI document assistant built with Python.

## Tech Stack

- Django: Main web server
- SQLite: Database
- FastAPI: AI API server (planned)
- LangChain: RAG pipeline (planned)
- Local LLM: Apple Silicon (planned)

## Development Roadmap

- [x] Step 1: Django environment setup
- [x] Step 2: ML/DL and Local RAG
- [ ] Step 3: FastAPI integration
- [ ] Step 4: Django-FastAPI integration
- [ ] Step 5: AI analysis and macOS app packaging

## Getting Started

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
